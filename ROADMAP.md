# Roadmap

These are ideas, not implemented features or promises. This cleanup preserves the existing app behavior.

## Before broader public use

- Invitation-only registration and usage limits.
- Account recovery, administration and storage controls.

## Interface and scanning

- Consider bottom navigation and separate Friends and Trades tabs.
- Rename Queue to Book Queue.
- Add a Settings page for secondary-review options and sign-out confirmation.
- Optional bulk acceptance of reviewed scans, with a clear warning about AI errors.
- Simplify lists and filters.
- Consider a shorter minimum password while retaining suitable account protection.

## Profiles and friends

- Add display names alongside usernames.
- Optional friend discovery through mutual friends or location, with privacy controls.
- Private-library-only accounts and controls over discoverability.
- Optional email notifications for trade requests.

## Reading features

- Book reviews and personal reading statistics.
- Track unique books, reviews, trades, books received and pages read.
- An optional popular-books section.
